# Security Policy

## Reporting a vulnerability
Do not open a public issue. Use the "Report a vulnerability" button on the
Security tab. Include the affected module, version, impact, and steps to reproduce.

## What to expect
- Acknowledgement within 3 business days
- Assessment within 7 business days
- Fixes shipped as a new tagged version with a changelog entry

## Scope
Terraform modules in this repository. This repo must never contain real
credentials or account data. If you find any, report it immediately.
